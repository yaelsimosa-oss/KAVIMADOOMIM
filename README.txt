מדריך זוגיות מיטיבה | פורום נראות בשיתוף קווים אדומים
=====================================================

העלאה לשרת
-----------
1. מעלים את כל תוכן התיקייה (כולל התיקיות fonts ו-assets) לתיקיית האתר בשרת
   (למשל public_html, או לתת-תיקייה כמו /guide).
2. הקובץ הראשי: index.html
3. אין צורך בשרת צד-שרת, מסד נתונים או התקנות – זהו אתר סטטי.
   מתאים גם ל-Netlify / Vercel / GitHub Pages / כל אחסון סטטי (גרירת התיקייה).

מבנה הקבצים
-----------
index.html        – המדריך המלא
cards.html        – כרטיסיות לשיחה בפורמט A4 להדפסה ולשמירה כ-PDF
guide.css         – עיצוב
guide.js          – אינטראקציות (ניווט, כרטיסיות, שלבים)
guide-data.js     – תוכן הכרטיסיות, המצבים והשלבים
fonts/            – גופני Heebo ו-Assistant (מקומיים, ללא תלות באינטרנט)
assets/           – לוגו פורום נראות
.htaccess         – הגדרות קידוד ומטמון לשרתי Apache (אופציונלי)

הערות
-----
- כל הקבצים מקודדים ב-UTF-8.
- האתר עובד גם בפתיחה מקומית (לחיצה כפולה על index.html).
- עדכון תוכן הכרטיסיות / המצבים / השלבים: guide-data.js. שאר התוכן: index.html.
